# DECISIONS.md - AI-EL

This document records important project decisions, their rationale, and changes made during development.

## Decision 1: Project Scope

**Decision:** Develop AI-EL as a women's safety and emergency support platform for Kazakhstan.

**Reason:** The project addresses a meaningful real-world problem and combines mobile development with substantive AI functionality.

**Status:** Planned.

## Decision 2: Bilingual Support

**Decision:** Support Kazakh and Russian languages.

**Reason:** These languages are important for accessibility among the target users in Kazakhstan.

**Status:** Planned.

## Decision 3: Mobile Application

**Decision:** Use Flutter for the mobile application, with Android as the initial MVP target.

**Reason:** Flutter provides a cross-platform development approach and allows the project to potentially support iOS in the future.

**Status:** Planned.

## Decision 4: AI Architecture

**Decision:** Use Retrieval-Augmented Generation (RAG) combined with AI agent tools.

**Reason:** RAG can ground answers in selected official sources, while agent tools can perform specific information retrieval tasks.

**Status:** Planned.

## Decision 5: Knowledge Sources

**Decision:** Prioritize official Kazakhstan information sources, including gov.kz and adilet.zan.kz.

**Reason:** Legal and safety-related information should be based on trustworthy and verifiable sources.

**Status:** Planned.

## Decision 6: Privacy and Emergency Features

**Decision:** Make location sharing and access to sensitive user information permission-based.

**Reason:** The application handles potentially sensitive safety-related information and must prioritize user privacy.

**Status:** Planned.

## Decision 7: Development with an AI Coding Agent

**Decision:** Use an agentic coding tool to plan, implement, test, and debug the project directly in the repository.

**Reason:** Agentic development is a mandatory requirement of the course.

**Status:** Planned.
